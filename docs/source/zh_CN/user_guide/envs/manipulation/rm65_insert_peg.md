# RM65 插销插入

## 概述

本文档描述位于 `rm65_insert_peg` 目录下实现的插销插入操作任务。该环境使用 RM65 六自由度机械臂与并联夹爪，目标是靠近插销、稳定抓取、抬起搬运，并将插销准确插入插座。代码同时注册了 `rm65_insert_peg` 和 `peg-insert` 两个环境名称，二者指向同一套环境与训练配置。

## 环境描述

该任务基于 RM65 机械臂、自由插销与固定插座场景构建。以下示例使用 `rm65_insert_peg`，也可以使用兼容别名 `peg-insert`。

### 机器人结构

RM65 机器人在该环境中包含以下主要部分：

-   **基座（base_link）**：固定在工作台前方
-   **6 个机械臂关节**：`joint_1` ~ `joint_6`
-   **并联夹爪**：主驱动关节为 `gripper_Left_1_Joint`，其余夹爪关节通过联动关系同步
-   **末端执行器（TCP）**：`gripper` 站点，用于计算工具中心点与插销之间的相对关系
-   **手指接触点**：`left_finger_pad`、`right_finger_pad`，用于评估预抓取对齐、抓取对称性和脱手情况

### 场景物体

-   **工作台**：为任务场景提供支撑平面
-   **自由插销**：`peg`，圆柱形物体，配置长度为 `0.10 m`，半径为 `0.015 m`
-   **插座组件**：以 `socket_base` 为中心，目标插孔区域由 `socket` 表示
-   **插座参数**：配置插孔深度 `0.08 m`、名义半径 `0.016 m`、插入成功深度阈值 `0.045 m`

### 任务目标

机器人需要完成以下阶段：

1. **靠近插销**：将 TCP 和双指中点移动到插销上方
2. **准备抓取**：保持夹爪张开，并持续改善横向和高度对齐
3. **稳定抓取**：闭合夹爪包住插销并连续保持稳定的抓取
4. **搬运到插座**：在保持插销竖直的同时将其移动到插座上方
5. **对齐并插入**：减小 XY 误差，下探进入插孔入口，并完成插入

## 动作空间

动作空间为 `Box(-1, 1, (7,), float32)`。

其中前 6 维控制机械臂运动，最后 1 维控制夹爪开合。

### 控制模式

-   **机械臂**：使用增量式关节目标控制
    前 6 维动作先乘以 `0.025`，再加到当前关节位置上，最后裁剪到配置的关节限制范围内
-   **夹爪**：使用带安全门控的二值开合控制
    最后一维原始动作大于 `0.2` 时表示请求闭合，但只有在双指中点与插销的 XY 距离小于 `0.032 m`、中点相对插销的高度偏差位于 `(0.003, 0.05) m`，且插销竖直度大于 `0.90` 时，闭合请求才会生效。有效闭合目标为 `-0.91`，其他情况保持张开目标 `0.0`。一旦抓取成功标志建立，夹爪会锁定为闭合状态。

### 动作维度详细说明

| 编号 | 动作说明     | 原始输入范围 | 实际控制对象           |
| ---- | ------------ | ------------ | ---------------------- |
| 0    | 关节 1 增量  | `[-1, 1]`    | `joint_1`              |
| 1    | 关节 2 增量  | `[-1, 1]`    | `joint_2`              |
| 2    | 关节 3 增量  | `[-1, 1]`    | `joint_3`              |
| 3    | 关节 4 增量  | `[-1, 1]`    | `joint_4`              |
| 4    | 关节 5 增量  | `[-1, 1]`    | `joint_5`              |
| 5    | 关节 6 增量  | `[-1, 1]`    | `joint_6`              |
| 6    | 夹爪开合命令 | `[-1, 1]`    | `gripper_Left_1_Joint` |

### 控制约束

-   控制周期 `ctrl_dt = 0.01s`，对应 100Hz 控制频率
-   物理仿真步长 `sim.dt = 0.002s`
-   机械臂每步动作缩放系数为 `0.025`
-   6 个关节的控制范围分别裁剪到 `[-2.0, 2.0]`、`[-1.5, 1.5]`、`[-1.5, 1.5]`、`[-2.0, 2.0]`、`[-1.5, 1.5]`、`[-1.57, 1.57]`
-   夹爪关节裁剪到 `[-0.91, 0.0]`

## 观测空间

观测空间为 `Box(-inf, inf, (45,), float32)`。

### 观测组成

观测由以下 5 部分拼接而成：

1. **机器人关节状态（16 维）**
    - 相对于复位姿态的机器人关节位置
    - 策略使用的机器人关节速度
2. **任务绝对位置（6 维）**
    - 插销位置
    - TCP 位置
3. **手部到插销的抓取特征（14 维）**
    - TCP 到插销的方向和距离
    - 双指中点到插销的方向和距离
    - 中点高度偏差、双指平衡度、手指到插销距离以及指间距
    - 夹爪闭合比例
4. **插销姿态与插座相对特征（7 维）**
    - 插销轴向方向
    - 插销到插座的方向和距离
5. **离散任务指示量（2 维）**
    - 当前夹爪命令
    - 抓取成功标志

### 观测维度详细说明

| 编号范围 | 内容说明                 | 维度 |
| -------- | ------------------------ | ---- |
| 0-7      | 相对机器人关节位置       | 8    |
| 8-15     | 机器人关节速度           | 8    |
| 16-18    | 插销位置                 | 3    |
| 19-21    | TCP 位置                 | 3    |
| 22-24    | TCP 到插销的方向         | 3    |
| 25-25    | TCP 到插销的距离         | 1    |
| 26-28    | 双指中点到插销的方向     | 3    |
| 29-29    | 双指中点到插销的距离     | 1    |
| 30-30    | 双指中点到插销的垂直偏差 | 1    |
| 31-31    | 左右手指平衡度           | 1    |
| 32-32    | 左手指到插销距离         | 1    |
| 33-33    | 右手指到插销距离         | 1    |
| 34-34    | 指间距                   | 1    |
| 35-35    | 夹爪闭合比例             | 1    |
| 36-38    | 插销轴向方向             | 3    |
| 39-41    | 插销到插座的方向         | 3    |
| 42-42    | 插销到插座的距离         | 1    |
| 43-43    | 当前夹爪命令             | 1    |
| 44-44    | 抓取成功标志             | 1    |

### 观测说明

-   与插座相关的特征只有在抓取建立后才会被激活
-   当前夹爪命令是门控后的执行器目标，只会取张开值 `0.0` 或闭合值 `-0.91`，并非策略输出的原始第 7 维动作
-   抓取成功需要候选抓取连续保持至少 3 个控制步；标志建立后会在当前 episode 内保持为真
-   返回观测前会将 `NaN` 或无穷值替换为有限数值，避免策略输入异常

## 奖励函数

奖励函数采用分阶段复合设计，同时鼓励搜索、预抓取对齐、稳定抓取、抬升搬运与插入成功。

### 主要奖励项

1. **接近插销奖励**

    当夹爪保持张开时，奖励双指中点在 XY 平面和高度方向上持续靠近插销。

2. **预抓取与闭合奖励**

    引导机械臂在夹爪张开状态下完成预抓取对齐，并奖励在有效抓取区域内及时闭合夹爪。同时惩罚在抓取区外过早闭合、在预抓取区域长时间停滞，以及已经进入有效抓取通道后仍迟迟不执行闭合动作。

3. **抓取建立奖励**

    奖励手指对称包围、夹爪闭合程度提升、连续多步稳定捕获，以及首次成功抓住插销的时刻。

4. **抬升与搬运奖励**

    奖励将插销从桌面抬起、保持插销竖直、持续保持抓取，并朝插座中心移动。

5. **插入奖励**

    ```python
    insert_reward = insert_depth * reward_cfg.insert_weight * 6.0
    depth_insert_bonus = reward_cfg.depth_insert_bonus * np.tanh(insert_depth / 0.01)
    ```

    奖励朝插孔入口下探、增加插入深度，并在插座附近维持良好的对齐姿态。只有已经建立抓取、XY 误差小于 `0.008 m` 且插销竖直度大于 `0.97` 时，插入深度才会计入任务跟踪。

6. **对齐与精度奖励**

    当抓取后的插销到达插座区域、以合理姿态接触插座并进一步缩小 XY 误差时，会获得额外奖励。

7. **成功奖励**

    当满足以下条件时任务判定成功：

    ```python
    success = (insert_depth > 0.045) & (xy_dist < 0.003) & (peg_uprightness > 0.98)
    ```

    成功后额外增加 `1500.0` 奖励。

### 惩罚项

1. **停滞与插座附近悬停惩罚**

    惩罚在预抓取阶段停留过久不执行抓取、搬运到插座过程中没有推进，以及在插座附近保持过高或迟迟不下探。

2. **过早闭合与弱抓取惩罚**

    惩罚在奖励定义的预抓取区域外闭合夹爪，或在成功捕获后夹爪闭合程度与指间距对应的抓取强度过弱。环境在抓取成功后会强制保持闭合命令。

3. **碰撞、倾斜与抖动惩罚**

    惩罚预抓取阶段撞动插销、插销倾斜过大、下坠，以及插销线速度过高。

4. **偏离插座与过早下探惩罚**

    惩罚抓取后远离插座，或在横向尚未对齐时过早向下插入。

5. **动作与速度惩罚**

    惩罚连续动作变化过大、机器人关节速度过大，以及插销速度过大。

6. **终止惩罚**

    当触发终止条件时，会额外施加 `-50.0` 惩罚；最终奖励会裁剪到 `[-100.0, 3000.0]`。

## 初始状态

### 机器人初始化

-   机械臂默认关节初值为 `[0.09, 0.71, 0.92, -0.18, 1.19, -0.85]`
-   夹爪默认处于张开状态
-   关节复位噪声按 `0.005` 的幅度均匀采样
-   机器人关节速度初始化为零

### 场景初始化

-   插座固定在机器人前方
-   插销以单位四元数姿态竖直放置
-   插销初始位置在桌面上采样：
    -   `x` 范围：`0.50 ~ 0.62`
    -   `y` 范围：`-0.10 ~ 0.10`
    -   `z` 位置：`0.052 +/- 0.0015`

### 随机化内容

每次 reset 会重新采样以下因素：

-   机器人关节复位噪声
-   插销 XY 初始位置
-   插销 Z 初始位置
-   插销与插座的初始 XY 距离，约束在 `0.08 ~ 0.18 m`

---

## Episode 终止条件

以下任一条件满足时，episode 会提前终止：

1. **插销下落过低**
    - 阈值：`peg_z < -0.15`
2. **抓取后掉落**
    - 条件：之前已建立抓取，且 `hand_to_peg_dist > 0.12`，同时 `peg_z < 0.09`
3. **机器人关节速度过大**
    - 阈值：任意关节速度绝对值超过 `30`
4. **插销线速度过大**
    - 阈值：插销任意线速度分量绝对值超过 `15`

此外，环境最大时长为 `3s`。

## 使用方法

当前任务提供 Async FastSAC 配置：默认使用 `2048` 个并行训练环境和 `16` 个评估环境，随机种子为 `42`，训练 `20,000` 个学习迭代，并每 `1,000` 个迭代保存一次检查点。

### 训练

```bash
python scripts/train.py task=rm65_insert_peg/motrix.fastsac
```

### 策略评估

```bash
python scripts/play.py env=rm65_insert_peg num_envs=16
```

### TensorBoard

```bash
tensorboard --logdir runs/rm65_insert_peg/fastsac
```
