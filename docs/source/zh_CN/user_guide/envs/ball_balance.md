# 球平衡（Microduck）

## 概述

球平衡任务让 14 自由度小型双足机器人 Microduck 双脚站在一颗自由篮球（半径 0.14 m）上并保持平衡。机器人需要通过全身关节协调动作，既维持自身直立，又把不断滚动的球保持在双脚下方。该环境基于 Manager 工作流实现，仿真后端通过配置选择，物理参数不做域随机化。

## 运行命令

不训练，直接预览环境：

```bash
python scripts/view.py env=microduck-ball-balance
```

使用内置的 Motrix FastSAC 配置训练（该任务目前只提供这一个训练配置，`num_envs=2048`，训练 20000 次迭代）：

```bash
python scripts/train.py task=microduck-ball-balance/motrix.fastsac
```

加载训练结果评估：

```bash
python scripts/play.py env=microduck-ball-balance
```

## 动作空间

动作空间为 14 维关节位置目标，对应 Microduck 的全部驱动关节（左腿髋偏航/侧摆/俯仰、膝、踝，颈部俯仰，头部俯仰/偏航/侧翻，右腿同名五关节）。

策略动作按如下方式转换为关节位置目标：

```
目标关节角度 = 默认站立姿态 + 动作值 × 0.5
```

动作缩放系数 `action_scale=0.5` 为全关节统一值；动作空间边界由每个关节在模型中的 `ctrl_range` 推导。底层为位置执行器，PD 增益与力矩限制以机器人模型为唯一来源。

## 观察空间

策略观察共 54 维，价值（critic）观察共 63 维，包含额外的特权信息且不加噪声。

| 观察 | Actor | Critic | 含义 |
| ---- | ----: | -----: | ---- |

| 基座线速度 | — | 3 | 基座线速度，特权观察，无噪声 |
| 球相对位置 | 3 | 3 | 球心相对基座的位置（基座坐标系），均匀噪声 [0, 0.02)（仅 actor） |
| 球相对速度 | 3 | 3 | 球线速度（基座坐标系），均匀噪声 [0, 0.1)（仅 actor） |
| 球世界位置 | — | 3 | 球心世界坐标，特权观察 |
| 球世界速度 | — | 3 | 球线速度世界坐标，特权观察 |
| 关节角度 | 14 | 14 | 相对默认姿态的关节角偏移，均匀噪声 [0, 0.01)（仅 actor） |

## 奖励设计

奖励由多个指数核项与惩罚项组成。指数核项形如 $\exp(-e^2/\sigma^2)$，其中 $e$ 为对应误差，误差越小奖励越接近 1。

| 奖励项 | 权重 | 计算方式 | 设计目的 |
| ------ | ---: | -------- | -------- |
| `alive` | 1.0 | 每步常数 1.0 | 存活保底，避免策略通过快速终止逃避动作变化率惩罚 |
| `upright` | 4.0 | 基座坐标系重力方向的指数核（σ=0.2） | 保持躯干直立 |
| `ball_under_feet` | 3.0 | 球心到双脚中点水平距离的指数核（σ=0.05） | 把球保持在双脚正下方，是任务核心 |
| `base_height` | 1.5 | 基座高度对目标值 0.40 m（= 0.12 + 2×0.14，即站上球顶后的躯干高度）的指数核（σ=0.05） | 维持站在球上的平衡高度 |
| `dof_default` | 0.5 | 关节角相对默认姿态均方偏差的指数核（σ=0.5） | 鼓励贴近默认站姿，抑制多余动作 |
| `action_rate_l2` | −0.5 | 相邻两步动作差的 L2 范数 | 抑制抖动的动作序列 |
| `limits_dof_pos` | −5.0 | 关节角接近限位的软惩罚（soft_limit=0.9，上限 cap=5.0） | 避免顶死关节限位 |
| `undesired_contacts` | −0.2 | 非足端 link 的接触力（阈值 0.5） | 惩罚躯干等部位触地或碰球 |

## 终止条件

以下条件满足任意一条时回合以 `terminated`（失败）结束：

| 类型 | 条件 | 含义 |
| ---- | ---- | ---- |
| 高度失败 | 基座高度 < 0.22 m | 跌落或从球上掉下 |
| 姿态失败 | 基座坐标系重力的水平分量 > 0.6（约 37° 倾斜） | 严重侧倾 |
| 球脱离 | 球心到双脚中点的水平距离 > 0.20 m | 球滚出脚底 |
| 关节位置异常 | 任一关节超出限位 0.5 rad 以上，或关节角非有限值 | 数值发散或关节限位失效 |
| 关节速度异常 | 任一关节速度绝对值 > 100 rad/s，或非有限值 | 数值发散 |

回合达到 20 s（1000 个控制步）时以 `truncated`（时间截断）结束，不属于失败。

## 重置逻辑

每个回合开始时的确定性状态与随机采样如下。重置采样均为均匀分布（区间 [0, scale)）：

- 机器人基座位姿：位置 (0, 0, 0.40) 加 XY 各 [0, 0.02) m、Z [0, 0.005) m 噪声；姿态直立，三轴欧拉角各加 [0, 0.05) rad 噪声；
- 机器人关节：设置为默认站立姿态，每关节加 [0, 0.05) rad 噪声（裁剪到限位内），关节速度置零；
- 基座线速度：零加均匀噪声（XY [0, 0.1) m/s，Z [0, 0.05) m/s）；角速度：零加 [0, 0.2) rad/s 噪声；
- 篮球：球心置于 (0, 0, 0.14)（即接触地面），XY 各加 [0, 0.01) m 噪声，线速度加均匀噪声（XY [0, 0.05) m/s），角速度置零。

物理域随机化：该环境**不随机化**质量、惯量、摩擦或执行器增益等物理参数；上述随机化仅覆盖初始状态，观察噪声仅作用于 actor 观察。
